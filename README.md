# Modern-callout

**Modern-callout** is a QGIS Print Layout plugin that inserts sleek, smoked-glass HTML callout cards paired with native vector leader lines and variant marker icons (`brand`, `info`, `success`, `warning`, `danger`).

## Features / Funcionalidades

- **Smoked-Glass HTML Frame (`modern-callout N`):** Native `QgsLayoutFrame` pre-configured with glassmorphism CSS in the User Stylesheet and clean semantic HTML in the Source tab.
- **Native Leader Line (`polilinha N`):** Vector `QgsLayoutItemPolyline` matching the selected variant color, editable via the QGIS *Edit Nodes* tool.
- **Variant Marker Icon (`icone texto N`):** Native `QgsLayoutItemLabel` displaying the variant Unicode symbol (`◉`, `ⓘ`, `✔`, `⚠`, `✖`).
- **Bilingual Interface:** Automatically adapts to Portuguese (`pt-BR`) and English (`en`).
